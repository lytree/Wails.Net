## 5. 对下一轮基线同步的结论

**范围预估：下一轮 `v3.2.0` 正式版对本移植几乎是“零代码改动”批次。**

1. **P0 阻断：0 项**。本轮无安全修复、无协议/传输变更、无破坏性 API 变更（`#6077` 仅改注释，字段名未变）。
2. **P1 行为差异：0 项**。两个功能性 PR（`#6502`、`#6314`）在 .NET 侧均已具备等价语义：
   - `SetIcon` 已是应用级并作用于已有窗口与新窗口；
   - Linux 托盘菜单在每次弹出时从源 `Menu` 重建，`Menu.Update/Clear/Add` 的变更能在下次弹出时体现（与上游“立即重建 dbusmenu” observable 结果一致）。
3. **P2 增强：2 项（均可选）**
   - **HICON 生命周期**：为 `WindowsPlatformApp` 增加「缓存当前 HICON + 替换/销毁时 `DestroyIcon`」或对 `LoadIconFromBytes` 结果在窗口销毁时释放。属轻微句柄泄漏，长期运行 + 频繁换图标/多窗口场景才可观察。
   - **`DisableIcon` 选项**（`Windows.WebviewWindowOptions`）：本移植缺失该选项，因此上游 `WS_SYSMENU` 规避逻辑无从落地。标注为⛔不适用，**不作为本轮同步项**；如未来补齐该选项，再一并移植规避逻辑。
4. **无需改动**：`#6077`、`#6314` 的 gtk3 分支、`#6348`、版本 bump、文档/物料。
5. **基线口径**：`v3.1.0` 保持不变，直到出现新的 weekly/hotfix 正式版（预计 `v3.2.0`）。届时建议用本报告 §3 表逐条复评，尤其是 `#6502` 的句柄释放与 `#6314` 的托盘刷新是否在正式版中被进一步修改。
