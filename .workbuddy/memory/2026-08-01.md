## 分支 feature/lybox-vue-app：移植 AvaloniaTemplate(LYBox) 功能项到 Wails.Net

在 `examples/LyboxApp/` 新建宿主应用，用 Wails.Net 实现 AvaloniaTemplate 的功能项，前端采用 **Vue 3 + vue-jsx-vapor(TSX) + TailwindCSS**。

- 宿主（C#）：`LyboxApp.csproj`（复用 Vue Demo 的前端自动构建 Target，改用 npm）/ `Program.cs`（注册 CorePlugin + 6 个功能插件，挂载 LyboxEventBus 到 app.Events.Emit）。
- 核心服务 `Services/Core/`：`SettingsStore`(lybox-settings.json 持久化)、`LyboxEventBus`、`TaskRegistry`、`LyboxCoreService`(GetPlugins/GetNavigation/SetPluginEnabled/GetTasks/GetAppInfo)、`SettingsService`、`LocalizationService`。每个插件在 ConfigureServices 中以单例注册 `PluginManifest` 与 `NavItem`（DI 的 `IEnumerable<T>` 注入聚合）。
- 功能插件 `Plugins/`（移植 LYBox 演示插件）：Template / ButtonsInputs / DateTime / DialogFeedbacks(事件驱动对话框) / Downloader(HttpClient 流式下载+进度上报任务托盘) / NavigationMenus(菜单树)。
- 前端 `frontend/`（Vite + vue-jsx-vapor + Tailwind v3）：侧边栏导航、顶栏(语言/主题)、仪表盘、插件管理、设置、任务页、6 个演示页、DialogHost、TaskTray；通过 `window.wails.call` 调 [Binding] 服务，事件 `lybox:*` 驱动。
- 约定：Wails.Net 绑定 JSON 用 camelCase（前端读 camelCase 字段）；事件载荷用 `Dictionary<string,object>` 固定键名规避命名策略差异。
- 前端已 `npm run build` 通过（27 modules，Tailwind CSS 产出）。`vue-jsx-vapor` 固定 `2.5.4-beta.1` + `--legacy-peer-deps`（与 Vue Demo 一致；registry 最新 2.7.4 要求 vue 3.6）。
- 后端 `dotnet build` 验证中（后台任务）。
